# Sources

Two kinds of source feed the same lens. Drop any source that doesn't return a dated item from the last 30 days.

## Written sources

News sites, company blogs, changelogs and release notes, paper listings, social searches, forums and newsletters. Prefer an RSS or Atom feed, then a changelog or listing page, then a saved search.
